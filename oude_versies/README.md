# Oude versies

Alleen ter referentie, of om terug te vallen als een nieuwe versie niet bevalt.
**Deze bestanden worden nooit door de automatische update gebruikt.** Die kijkt alleen naar
`mc_server_manager.py` in de hoofdmap. De volledige lijst met wijzigingen staat in [`CHANGELOG.md`](../CHANGELOG.md).

Terugvallen? Kopieer het gewenste bestand naast je instellingen, hernoem het (bijvoorbeeld naar `mc_server_manager.py`)
en start het. Zet daarna de automatische programma-update uit (Instellingen → Dit programma), anders haalt het programma
zichzelf weer naar de nieuwste versie.

## Oudere reeks (vóór 2.2)

| Bestand | Versie | Opmerking |
|---|---|---|
| `mc_server_manager_2.1.py` | 2.1 | Bereikbaarheid-tabblad, speleracties in de console, tabbladen omgewisseld. |
| `mc_server_manager_2.0.py` | 2.0 | Nieuwe naam "MC Server Manager" en een strengere schone console. |
| `mc_updater_1.3.py` | 1.3 | TPS-fix, grafiek met instelbaar tijdvenster en auto-zoom, RAM wijzigen. |
| `mc_updater_1.2.py` | 1.2 | Eerste versie met het Server-tabblad (start/stop, console, statistieken, spelers). |
| `mc_updater_1.1.py` | 1.1 | Alleen plugins en server.jar bijwerken (nog zonder Server-tabblad). Heette nog "MC Server Updater". |

Versie 1.0 (de allereerste versie, alleen plugins via Modrinth en Paper bijwerken) is niet bewaard.
De huidige versie staat in [`mc_server_manager.py`](../mc_server_manager.py).

Let op: de oude versies bewaren hun instellingen in `mc_updater_config.json` (tot 1.3) of
`mc_server_manager_config.json` (vanaf 2.0), naast het programma. Nieuwere versies kunnen instellingen hebben die
oudere versies niet kennen; die worden dan genegeerd.
